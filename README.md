# Lona Salon

موقع عربي متجاوب لمشغل Lona Salon، يعرض الخدمات والأسعار والعروض ومعرض الأعمال وآراء العميلات، ويتيح إرسال طلب الحجز عبر واتساب.

## التقنيات

- HTML5
- CSS3
- JavaScript بدون مكتبات خارجية
- موقع Static بدون قاعدة بيانات أو Backend

## التشغيل محليًا

يجب تشغيل الموقع عبر خادم محلي لأن `header.html` و`footer.html` يتم تحميلهما باستخدام `fetch`:

```powershell
python -m http.server 8123
```

ثم افتح:

```text
http://127.0.0.1:8123/index.html
```

## التعديلات الشائعة

- **رقم واتساب:** ابحث عن `966500000000` في `index.html` و`footer.html` واستبدله بالرقم الدولي دون علامة `+` في روابط واتساب.
- **اسم المشغل:** ابحث عن `Lona Salon` في `index.html` و`header.html` و`footer.html`.
- **الشعار:** استبدل `media/logo.png` بصورة تحمل الاسم نفسه، أو حدّث المسار في `header.html` ووسوم الصفحة داخل `index.html`.
- **الخدمات والأسعار والعروض:** عدّل الأقسام المقابلة داخل `index.html` مع الحفاظ على أسماء الأصناف CSS الحالية.
- **صور المعرض:** الصور منظمة داخل `media/gallery/`. حدّث صور الغلاف في HTML وقائمة `galleryData` في JavaScript عند إضافة صور جديدة.
- **الفيديو:** استبدل `media/video2.mp4` أو حدّث مساره داخل قسم Hero.
- **بيانات التواصل:** توجد داخل `footer.html` وقسم التواصل في `index.html`.

## الحجز

يتم إنشاء رسالة من بيانات النموذج وفتحها في واتساب. لا يُرسل الطلب قبل الموافقة على شروط الحجز وسياسة العربون. الموقع لا يخزن بيانات الحجز.

## النشر

يمكن نشر المجلد كما هو على GitHub Pages أو Netlify أو Cloudflare Pages أو أي استضافة Static. بعد النشر:

1. اختبر الصفحة والرابط على الجوال والكمبيوتر.
2. أضف رابط الموقع النهائي إلى `og:url` داخل `<head>` في `index.html`.
3. يفضّل استخدام رابط مطلق لصورة `og:image` بعد معرفة النطاق النهائي.
4. حدّث روابط Instagram وSnapchat في `footer.html` بروابط حسابات المشغل الفعلية.

## ملفات المشروع

- `index.html`: الصفحة والتنسيقات والوظائف.
- `header.html`: الهيدر وروابط التنقل.
- `footer.html`: الفوتر وروابط التواصل.
- `media/`: الشعار والفيديو وصور المعرض.
- `CLIENT-GUIDE.md`: تعليمات مبسطة لمالكة الموقع.
